# Hardware photo provenance

The photos below document the shared robot platform used for development and testing. They provide hardware context and do not imply sole authorship of the physical build.

| Image | Source | Description |
| --- | --- | --- |
| [Finished robot](roverlink-robot.jpg) | Supplied group report, PDF page 7, Figure 6 | Final robot configuration with its enclosure and top-mounted LiDAR. |
| [Hardware during assembly](roverlink-hardware.jpg) | Supplied group report, PDF page 3, Figure 2 | Open chassis showing the wheels, electronics, wiring and sensor stack. |

Both images were extracted from the PDF's embedded raster images and converted to JPEG at their native resolution. No cropping, retouching, resizing or generated content was applied. Report text, page headers and author names are outside these extracted images and are not included. [Image dimensions and hashes](hardware-photo-manifest.json) record the exact published files.
